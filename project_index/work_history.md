## M-2026-05-01：query 分支扩展异常修复
- 版本号：发布版 v0.3.2（同步期）
- 日期：2026-05-10
- 影响范围：内部版 + 发布版
- 问题：仅传 query 字符串时，递归分支扩展表现异常，出现“候选高分但只替换一个”的逻辑症状。
- 根因：分支扩展参数入口存在遗漏，链路默认退化。
- 修复：补齐 `branch_expand_k` 参数透传，修正解耦版同步遗漏。
- 验证：多轮 query 日志比对，递归分支行为恢复可解释。
- 结论：召回覆盖恢复，后续需继续关注超窗场景下的扩展策略。

## M-2026-05-02：fallback 来源标记修复
- 版本号：发布版 v0.3.2
- 日期：2026-05-10
- 影响范围：内部版 + 发布版
- 问题：走本地 rerank fallback 时，`source` 仍显示 `llm`。
- 根因：来源字段赋值复用了主链路默认来源。
- 修复：按执行路径显式标注来源（`local_rerank`）。
- 验证：降级场景日志中 match.source 与 result_source 对齐。
- 结论：结果可解释性显著提升，可被上层 Agent 安全筛选。

## M-2026-05-03：评分映射策略调整
- 版本号：发布版 v0.3.2
- 日期：2026-05-10
- 影响范围：内部版 + 发布版
- 问题：fallback 结果出现“第一条极高、其余接近 0”的反直觉分布。
- 根因：归一化策略对单点信号过于敏感，且 fallback 分数上限未收敛。
- 修复：调整归一化映射与上限策略，使分数仍在 `[0,1]` 且保留置信度区分。
- 验证：噪声 query 与相关 query 两组对比，分布更平滑。
- 结论：分值解释性提升，但仍需持续观察长尾噪声行为。

## M-2026-05-04：ROOT/active 指针漂移事故修复
- 版本号：发布版 v0.3.2
- 日期：2026-05-10
- 影响范围：内部版 + 发布版
- 问题：在 active 子桶执行自动治理后，ROOT 可能被误切换。
- 根因：指针更新条件将 ROOT 与 active 混在同一 OR 判断。
- 修复：拆分条件：`source==root` 时仅改 root，`source==active` 时仅改 active。
- 验证：新增并通过 `test_root_active_pointer_stability.py`。
- 结论：拓扑入口稳定，事故级风险解除。
