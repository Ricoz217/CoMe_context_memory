## Alias 全链路收敛
- [ ] 已完成
- 目标版本：v0.3.3
- 优先级：P0
- 版本归属：发布版 + 内部版
- 背景：alias 映射/反解在多条链路散落，容易出现桶节点误映射。
- 目标：统一到 aliasing 模块，业务链路不再自行处理 alias 细节。
- 覆盖范围：query/optimize/split/compress/ingest/context_event/fallback。
- 验收标准：
  - 不再出现“bucket 被映射为 memory alias”错误。
  - payload 构造与 LLM 输出解析走统一入口。
  - 补充端到端 alias 一致性测试。

## Schema Migration System
- [ ] 已完成
- 目标版本：v0.3.3（框架）+ v0.3.4（首个真实迁移）
- 优先级：P0
- 版本归属：发布版主导，内部版同步验证
- 背景：已发布项目需要可控升级旧记忆库。

- 验收标准：
  - 老库可自动升级。
  - 迁移重复执行无副作用。
  - 失败可重试且不破坏存储。

## 大文本压力治理
- [x] 已完成
- 目标版本：v0.3.3
- 优先级：P0
- 版本归属：内部版先行，发布版同步
- 背景：大批量长文本入库后，治理链路可能被超窗反噬。
- 目标：确保治理机制在高压场景仍可执行、可收敛。
- 关键项：
  - 自动压缩/拆桶触发依据改为真实 token 压力（可带缓存）。
  - split fallback 对 bucket 主导场景也必须可拆。
  - optimize 输入负载收敛，避免无关 context 注入。
- 验收标准：
  - 压测场景下不出现死桶。
  - LLM 失败时本地兜底仍能完成治理动作。
